# Product Naming Options

## Purpose
Record candidate names for the portable single-computer diagnostic toolkit before any application-wide rename is attempted.

No files, manifests, windows, package metadata, or branding assets are renamed by this note.

## Options

1. **TriageOne**
   - Positions the toolkit as the first stop for one-computer diagnosis without sounding like a network scanner.

2. **CaseKit**
   - Emphasizes technician case work: collect evidence, organize findings, and support escalation.

3. **FieldScope**
   - Suggests a portable field technician console with enough breadth to inspect the whole workstation.

4. **EvidenceDesk**
   - Highlights trustworthy evidence gathering and review, which fits the triage bundle and reporting direction.

5. **RapidAssist**
   - Leans into speed and technician support while staying broad enough for repair, collection, and analysis workflows.

## Recommendation
Use **CaseKit** if the product should feel technician-focused and practical. Use **TriageOne** if the product should stay closest to the current computer-triage identity.
